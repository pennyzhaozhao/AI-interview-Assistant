实时提示板

听到面试官提问，几秒内给出第一人称的口语化回答。支持麦克风和会议软件声音，可最小化，并可在屏幕共享时隐藏。

截图解题

算法题、笔试题一键截图，按「思路 · 步骤 · 代码 · 复杂度」作答，代码框带行号与高亮，语言随你选。

个人知识库

导入简历、项目文档、PDF 和 GitHub 链接，回答引用你的真实经历，不编造项目和数据。

模拟面试与复盘

根据岗位和 JD 出题，用语音作答，逐题评分、点评并给出参考答案，评估报告可导出 PDF。

声纹识别

本地区分你和面试官的声音，你自己回答时不会被误当成新问题。声纹加密保存在本机，绝不上传。

三步开始

下载安装

macOS 下载 DMG 拖进「应用程序」；Windows 下载 exe 双击运行，无需安装。

填入你的 API Key

在「设置 → API 配置」选择模型服务商，填 Key 并测试连接。想零成本就用本地 Ollama。

准备资料，开始面试

填写岗位与 JD，选择知识库，点击「开始面试」或先来一场模拟面试。

常见问题

真的完全免费吗？

是的。App 本身免费且开源（MIT 协议）。你只需要为自己选择的模型服务商付费，费用按实际用量直接结算给服务商；使用本地 Ollama 模型则完全不需要 API 费用。

需要准备什么 API？

一个大模型 API Key（DeepSeek、OpenAI、Claude、Gemini、火山方舟任选其一），或在本机安装 Ollama。语音识别可用系统自带的本地识别，也可以配置豆包流式语音识别以获得更好的中文效果和会议软件声音识别。

我的数据安全吗？

面试历史、知识库和截图都保存在你的电脑上，项目没有任何接收数据的服务器。只有在你使用外部模型或语音服务时，请求所需的内容才会直接发送给你选择的服务商。API Key 保存在系统钥匙串 / Windows 凭据管理器中。

Windows 打开时提示「已保护你的电脑」怎么办？

Windows 版暂未进行代码签名，点击「更多信息 → 仍要运行」即可。请只从本项目的 GitHub Releases 下载。macOS 版已签名并通过 Apple 公证。

支持哪些语言？

界面支持简体中文和英文。面试官语言可单独设置为中文或英文，AI 回答会使用对应语言。

可以在任何面试中使用吗？

本项目适合面试练习、知识整理，以及在获得许可的场景中提供辅助。使用实时提示、录音或屏幕捕获前，请确认符合面试方规则、当地法律和第三方服务条款。
